> Instalar

Necesitas Node 20+…

Windows (PowerShell)

# instala Node 20+ desde nodejs.org, luego:
npm install -g noiracoder
noira login

macOS / Linux

# con Node 20+ ya instalado:
npm install -g noiracoder
noira login

Conecta gratis (1 min por clave)

noira connect   # guía: OpenRouter → Groq → Zen
noira "crea un hola mundo en mi proyecto"
