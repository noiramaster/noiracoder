# Git Flow — Noira

1. `git status` + `git diff --stat` para entender qué cambió.
2. Propone commit message (conventional: `feat:`, `fix:`, `refactor:`) — usuario aprueba con 1 click.
3. Nunca `git push --force` sin confirmación explícita.
4. Para PR: crea branch, commit, push, propone título + body.
5. Mensajes en idioma del usuario (detectado).

Nunca commitees secretos ni `node_modules`.
