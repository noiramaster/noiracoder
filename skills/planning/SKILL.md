# Planning — Noira

Formato (como OpenCode):

```
> Plan — <título>
  [ ] 1. <paso> — <archivo(s)>
  [ ] 2. <paso>
  [x] 3. <hecho>
```

Reglas:
- Máx 7 pasos, cada uno verificable.
- Marca `[x]` al completar, sin pedir permiso.
- Si un paso se complica, subdivide en 2.
- Al final: resumen de 2 líneas + siguiente paso sugerido.
